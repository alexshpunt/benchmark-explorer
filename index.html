      How these rankings work

      Only full benchmark runs count. A model needs at least three provider–harness routes; a harness needs at least three model–provider routes. Each route gets one vote. Models are first grouped by provider; harnesses use the newest accepted version on each route. Scores are medians. Price is the median cost of full runs with every trial priced; “—” means no complete price was reported. Score ranking keeps unpriced entries; Price and Balance exclude them. Balance adds the score rank and price rank with equal weight among entries with both. Bars show place in the selected ranking. These lists use the whole published snapshot, not the filters in the table above.

        How to read this matrix

        Rows are model routes and columns are harnesses. A compact harness column uses each model's latest available version and accepted run; hover a value to see that source. Use the arrow beside a harness to compare its versions side by side. Across all harnesses pools full runs for each model. In Score, Across all models shows the median score difference from pi-default on the same model families, with one vote per model and at least three matched families required. A plus sign means the harness scored higher than pi-default. Other metrics show medians across models. The top-left corner has no score. Only full benchmark runs contribute to summaries. In Score, an incomplete cell shows a dash and the largest single run's task count (N/total tasks) instead of a misleading score. Select a value to compare configurations, or select a row or column label to open details.
