Benchmark guide

These tasks ask an agent to make precise text changes with its tools. They test whether a model and its harness can find the right text, edit it safely, and produce the exact requested result—not solve a whole software project.

A run’s published score combines coverage with 75% first-attempt exact success and 25% final exact success after recovery. Exact means the resulting text matches the requested output. Complete runs enter the ratings below; partial results remain available as evidence.

The reference harness, baseline-agent, is a small Pi-based agent with Bash as its only tool. Harness ratings measure changes against its results on the same model-provider routes.

  • Model + harness: median full-run score of the latest complete harness version, selected separately for each model-provider route.
  • Model: median of its harness-combination scores. Every harness has one vote; extra repeats cannot increase its weight.
  • Harness: baseline mean plus the sum of measured differences divided by the fixed number of baseline routes. Unmeasured routes contribute zero change. Routes without a full baseline result are excluded; real zero scores are not missing.
  • Matrix: baseline routes are shown by default. Harnesses with more than three full model-route results get separate columns; rarer Pi extensions share pi-extensions, and other rare harnesses share Others. Groups with multiple visible members can be expanded. Single provider routes, single harness groups, and harnesses with one visible version stay direct.

Only complete accepted results enter ratings. Missing cells remain missing; baseline substitution happens only in harness totals. Coverage tells you how many baseline routes were actually measured.

Header estimates describe one full model × provider × harness × reasoning result, not a multi-model batch. They show the median and P10–P90 of positive, fully measured totals in the published snapshot. Prices depend on the model, provider, and harness.

How to read this matrix

Rows are model routes and columns are harnesses. A compact harness column uses each model's latest available version and accepted run; hover a value to see that source. Use the arrow beside a harness to compare its versions side by side. There is no model summary across harnesses. In Score, Across all models shows each harness's baseline-adjusted mean over the same full pi-default model–provider routes. Untested routes use their pi-default score. The change and measured coverage appear under the score. Other metrics show medians across measured model families. Only full benchmark runs contribute to summaries. In Score, an incomplete cell shows a dash and the largest single run's task count (N/total tasks) instead of a misleading score. Select a value to compare configurations, or select a row or column label to open details.
